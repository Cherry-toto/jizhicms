访问统计插件 v1.0

前台浏览量统计 + 浏览记录（PV / UV / 来源 / 设备 / 蜘蛛）
{fun JZLANG('插件功能')}
安装后自动统计前台所有页面的访问情况，无需修改任何模板代码：
1、统计概览：今日/昨日 PV、独立访客 UV、累计数据、近 N 天趋势、栏目排行；
2、浏览记录：每一条访问的时间、页面、标题、栏目、IP、系统/浏览器、手机端、来源（Referer）；
3、内容排行：按文章/商品等内容统计 PV、UV、最近访问时间，并给出前台链接；
4、清理记录：按天数保留或整体清空，明细数据可随时瘦身。
{fun JZLANG('工作原理')}
安装时插件会向系统钩子表 jz_hook 注册一个钩子（模块 home、控制器 Home、全部方法）， 并在 app/home/plugins/ 下放入采集器 VisitController.php。
每次前台页面被访问时先执行采集，再渲染页面，因此：
① 无需改动 frphp/、app/home/c/ 等系统文件；
② 卸载时自动移除钩子与后台菜单，系统保持干净。
{fun JZLANG('浏览量显示说明')}
当前模板详情页已自带 /common/gohits 访问计数（显示为“热度”）， 因此插件的“同步内容浏览量”默认关闭，避免重复计数。
如需在别处读取浏览量，可用插件接口：
/visit/num/molds/article/id/12.html　返回该内容的浏览量（纯数字，可直接 AJAX 使用）。
{fun JZLANG('转移到其他网站')}
在「插件管理 → 插件列表」中点击本插件的 导出，得到一个 zip 安装包；
在其他极致CMS站点把该 zip 放到 app/admin/exts/ 解压（或使用后台“下载插件”流程）， 然后在插件列表点击 安装 即可自动建表、注册钩子与菜单，无需手工配置。
